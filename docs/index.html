Features

Everything a serious DAW needs.

Studio-grade DSP, a Logic-style channel strip and proper plugin hosting — all in a single binary that compiles in under a minute.

8-band Channel EQ

HPF, low shelf, four peaks, high shelf, LPF — the Logic-style layout. Drag handles to set freq and gain, scroll to adjust Q, double-click to reset.

Real-time Spectrum

A 2048-point FFT analyzer overlays the EQ curve at 30 Hz so you can see exactly where the energy in your mix is sitting.

Voice Effects

Echo, reverb, soft-clip distortion, telephone and megaphone — applied per-track with one click. Voice presets bundle them into instant looks.

Built-in Instruments

Poly / Lead / Bass / Pad / Strings synths, Drum Machine, 808, Pluck, Arp and a Sampler — all native, all latency-free.

VST3 & LV2 Plugins

Drop any VST3 or LV2 plugin onto a track. Latency is compensated against the dry mix using per-channel ring buffers.

Multi-track Recording

Arm any MIDI or audio track and hit record. Musical Typing turns your keyboard into a MIDI controller when no hardware is plugged in.

Tempo-aware Audio

Audio clips can stretch to the project tempo via OLA running on a background thread — the audio thread never blocks waiting for it.

Auto-save & Undo

Every project mutation is journaled into the undo stack. Sessions auto-save to disk every few seconds — you'll never lose work to a crash.

Get started

Build it in 60 seconds.

MaiBand is a single CMake project — no Conan, no vendored Xcode workspace, no surprise dependencies. JUCE is fetched automatically.

C++20 JUCE 8 CMake Linux · macOS · Windows VST3 · LV2 
# Clone the repo
git clone https://github.com/bobwdmai/maiband.git
cd maiband

# Configure & build
cmake -S . -B build
cmake --build build --parallel

# Run it
./build/BandForge_artefacts/Debug/BandForge
